# ⚙️ Instalasi

Clone repository

```bash
git clone https://github.com/username/afone-store.git
```

Masuk ke folder

```bash
cd afone-store
```

Import database

```
database.sql
```

Jalankan XAMPP

- Apache
- MySQL

Buka browser

```
http://localhost/afone_store-main
```
